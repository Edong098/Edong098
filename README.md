### 🔥 Featured Projects

Here are some of the key projects I have built, showcasing my expertise across ML, Full-Stack development, and System Design:

#### 🗑️ [Smart Waste Classification](https://github.com/Edong098/Eksperimen_SML_AhmadJulHadi)
*An AI-driven image classification system targeting sustainable recycling by classifying waste into plastic, paper, and organic types.*
* **Technologies**: `Python`, `TensorFlow`, `Keras`, `MobileNetV2`, `Computer Vision`, `Google Colab`
* **Key Achievement**: Developed efficient transfer learning pipelines achieving high validation accuracy for real-time waste sorting.

#### 🌐 [gumibarengjaga.ai](https://github.com/Edong098/gumibarengjaga.ai)
*A modern, intelligent application built using TypeScript and advanced web technologies.*
* **Technologies**: `TypeScript`, `Node.js`, `AI APIs`, `Modern Web Architecture`
* **Key Achievement**: Implemented robust backend services and interactive modules for the core application.

#### 🎓 Learning Management System (LMS)
*A feature-rich education platform designed to facilitate course management, learning delivery, and assessments.*
* **Technologies**: `PHP`, `MySQL`, `Bootstrap`, `JavaScript`
* **Key Features**: Multi-role dashboards (student/instructor), course progression tracking, and secure assessment submission.

#### 📝 [AI-TEXT-DETECTION](https://github.com/Edong098/AI-TEXT-DETECTION)
*A machine learning tool designed to identify machine-generated text versus human-written text.*
* **Technologies**: `Python`, `Scikit-Learn`, `NLP Preprocessing`, `Pandas`
* **Key Features**: TF-IDF vectorization, classifier comparison, and automated text inspection dashboard.
